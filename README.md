# Ejercicio 11: Karl's Languages

- **Concepto:** Lists / Generic Types (`List<E>`, `ArrayList<E>`)
- **Plataforma:** Exercism (Java Track)

## Descripción del Problema
Ayudar a Karl a mantener un registro de los lenguajes de programación que aprende a lo largo del tiempo.

## Tareas a Implementar en `LanguageList.java`:
1. `isEmpty()`: Retorna si la lista no contiene ningún elemento.
2. `addLanguage(String language)`: Agrega un lenguaje al final.
3. `removeLanguage(String language)`: Elimina un lenguaje de la lista.
4. `firstLanguage()`: Retorna el primer elemento añadido.
5. `count()`: Retorna la cantidad total de elementos.
6. `containsLanguage(String language)`: Verifica si el lenguaje existe en la lista.
7. `isExciting()`: Retorna `true` si la lista contiene `"Java"` o `"Kotlin"`.

## Cómo ejecutar en Visual Studio / VS Code:
Abre `Main.java` y haz clic en **Run** o presiona `F5`.
